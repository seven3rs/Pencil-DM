PencilDownload Manager

Sharpen your downloads. A fast, open-source download manager for Windows, macOS and Linux.

Built with Rust and Tauri on top of aria2. Multi-connection downloads, a time-zone-aware scheduler and a browser extension in one small native app.

Version 0.1.0. Installers only: Windows, macOS and Linux packages on the Releases page.

Download

Installers only: no portable or unzip-and-run builds. Get them from the Releases page.

Windows

The -setup.exe installer. Installs for your user account only, and includes aria2.

macOS

The .dmg for Apple Silicon or Intel. Drag the app to Applications. aria2 is included.

Linux

The .deb (Debian, Ubuntu) or .rpm (Fedora and relatives). Both install the system aria2 package as a dependency.

Each release lists SHA256SUMS, the exact aria2 source tarball and its COPYING file. Compare the checksum of what you downloaded before installing.

What’s inside

The app is young, but these parts are already in the code.

Verified engine

aria2 is bundled with the Windows and macOS installers, from a pinned version checked against SHA-256 hashes. It is checked again on every launch; if it goes missing or gets modified the app does not run it and repairs it from a verified download. On Linux the system aria2 package is used.

Scheduler

Weekday rules with start and stop times in any time zone. Queued downloads resume at the start time and pause at the stop time, with an optional speed cap.

Browser extension

A companion extension for Chromium browsers and Firefox sends downloads to the app over a paired local connection.

Speed limits

Set a global limit or a limit for a single download, anywhere from 1 KiB/s to 1 GiB/s.

A queue you can scan

A fast list with filters for all, downloading, completed, paused and failed. Open the details panel or right-click for actions.

Actions when finished

Open the folder, play a sound, show a notification, run a program, or put the computer to sleep, hibernate or shut it down.

Local and careful

The app talks to the engine over loopback with a random secret created at each launch. File names and errors from the network are always shown as plain text, never as HTML.

Windows, macOS, Linux

One codebase for all three. Installers target Windows, macOS on Apple Silicon and Intel, and Linux .deb and .rpm packages.

Engine

aria2 as a child process

  1. Install

    Run the installer for your system. aria2 is bundled with the Windows and macOS installers. On Linux the package depends on the system aria2.

  2. Stay verified

    On launch the bundled engine is checked against its hash. If it is missing or modified, the app does not run it and repairs it from a verified download. On macOS and Linux you can also point the app to your own aria2.

  3. Download

    Paste links into the app, or send them from your browser with the extension.

Build from source

Most people should use the installers above. Building from source is for contributors.

# install dependencies
npm ci

# check, test and build the interface
npm run check
npm test
npm run build

# run the desktop app in development
npm run tauri dev

# build installers for your platform
npm run tauri build

You need a stable Rust toolchain, Node.js 22 with npm, and the Tauri system dependencies. On Ubuntu or Debian, install libwebkit2gtk-4.1-dev, libappindicator3-dev, librsvg2-dev and patchelf.

Where it stands

This is the first release, 0.1.0. Releases are installers only, and each one is verified by hand before it is published.

In progress

  • Browser extension. Pairing and sending downloads from Chromium and Firefox.
  • History and categories. Saving the download list and sorting files by type.
  • Scheduler. Time-zone rules, start and stop transitions, speed caps.
  • Tray polish. A cleaner system tray experience.

Planned

  • Media extraction. Download video and audio from supported pages.
  • Signed updater. Updates you can verify before they install.
  • End-to-end tests. Automated tests that drive the real desktop app.

Free code, protected name

Open source in the way Audacity is: you can use and change the code, but not pass off a modified version as the original.
