# Security review findings

This file records findings confirmed by source inspection and changes in this review. Commit hashes below identify the commits containing the remediation; CI results are reported separately from source changes. The review is not a penetration test or a guarantee that no other vulnerabilities exist.

## Accepted residual risks

- **Same-user process compromise:** not fully mitigated because the app, engine, downloads, and local state run under the same OS account. Full isolation would require a separate sandbox/user model and is outside this security-only patch.
- **System-installed engine authenticity:** on platforms that use a system `aria2c`, the app checks the reported minimum version but does not compare against an embedded binary hash. Users should obtain it from their OS package manager or another trusted source.
- **Downloaded content and post-download execution:** downloaded files are untrusted; execution/open actions must remain explicit user choices. No sandbox is provided.
- **Updater/release signing configuration:** source contains a configured updater public key, but this review cannot verify that CI has the matching private key or that published artifacts are actually signed. A release should not be described as signed unless artifact signatures are verified.
- **Formal fuzzing and exhaustive Unicode behavior:** deterministic generated regression cases are included, but no coverage-guided fuzz campaign or full Unicode normalization/case-fold library was added in this change.
